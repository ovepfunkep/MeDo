# MeDo - Современное PWA-приложение для трекинга задач

## 🎯 Обзор проекта

MeDo - это современное, лёгкое и эстетичное PWA-приложение для трекинга задач, разработанное с акцентом на UX и минимальное количество действий для пользователя.

## 🛠️ Технологический стек

### Frontend
- **React 18+** с TypeScript
- **Tailwind CSS** для стилизации
- **Framer Motion** для анимаций
- **i18next** для интернационализации
- **React DnD** для drag-n-drop функциональности

### PWA-обвязка
- **vite-plugin-pwa** с Workbox
- **Manifest.json** + Service Worker
- **IndexedDB** (через idb) для хранения данных
- **Vite** как сборщик

### Хранилище данных
- **IndexedDB** как основное хранилище
- **LocalStorage** как fallback

## ✨ Реализованные функции

### 🎨 Пользовательский интерфейс
- **Современный дизайн** с чистыми линиями и минималистичным подходом
- **Адаптивная вёрстка** для мобильных и десктопных устройств
- **Тёмная и светлая темы** с плавными переходами
- **Анимации** на основе Framer Motion для улучшения UX

### 📱 Основной функционал
- **Добавление задач** с названием, описанием и выбором цвета
- **Редактирование задач** через модальное окно
- **Завершение задач** с перемещением в отдельную вкладку
- **Закрепление задач** для приоритетных элементов
- **Удаление задач** с подтверждением и функцией Undo

### 🎯 Интерактивность
- **Свайпы по задачам**:
  - Влево: завершить/восстановить задачу
  - Вправо: удалить (только для завершённых)
- **Drag-n-drop сортировка** задач
- **Floating Action Button** для быстрого добавления
- **Уведомления Snackbar** с возможностью отмены действий

### 🌍 Интернационализация
- **Поддержка двух языков**: русский и английский
- **Автоматическое определение языка** браузера
- **Переключатель языка** в заголовке приложения
- **Сохранение выбранного языка** в настройках

### 💾 Хранение данных
- **IndexedDB** для надёжного хранения больших объёмов данных
- **LocalStorage** как резервное хранилище
- **Автоматическая синхронизация** состояния с базой данных
- **Офлайн-режим** с полной функциональностью

### 📱 PWA функциональность
- **Установка на устройство** (мобильное/десктопное)
- **Иконка приложения** и splash-экран
- **Поддержка офлайн** через Service Worker
- **Автоматическое обновление** при выходе новых версий

## 🎨 Дизайн и UX

### Цветовая схема
- **Светлая тема**: белый фон с серыми акцентами
- **Тёмная тема**: тёмно-синий фон с контрастными элементами

### Навигация
- **Нижняя навигация** с двумя вкладками: "Активные" и "Завершённые"

- **Анимированный индикатор** активной вкладки

### Состояния
- **Пустые состояния** с понятными подсказками
- **Анимации загрузки** и переходов
- **Обратная связь** на все действия пользователя

## 📱 Демонстрация

Приложение полностью функционально и готово к использованию. Все основные функции протестированы и работают корректно:

1. **Создание задач** с различными параметрами
2. **Управление задачами** через свайпы и кнопки
3. **Переключение тем** и языков
4. **Навигация** между вкладками
5. **Сохранение данных** в IndexedDB
6. **PWA установка** и офлайн-работа

MeDo представляет собой полноценное, современное приложение для управления задачами, которое может конкурировать с коммерческими решениями благодаря продуманному UX и техническому исполнению.
